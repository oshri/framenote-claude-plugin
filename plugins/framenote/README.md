# FrameNote for Claude Code

Connects Claude Code to your FrameNote account, where film and video teams write scripts, cast and storyboard them, and review cuts.

With it, Claude can read your scripts as scene and shot outlines, show the cast and storyboard, summarise open review comments with their timecodes, and, on a read-write connection, start a script or storyboard, add a cut for review and invite or remove reviewers. Anything that spends credits or changes who can see a review asks first.

## Setup

1. In Claude Code, add the marketplace and install the plugin:

   ```
   /plugin marketplace add oshri/framenote-claude-plugin
   /plugin install framenote@framenote
   ```

2. Run `/mcp` and choose **framenote**.
3. Sign in to FrameNote in the browser that opens, and approve the connection.

A FrameNote account is needed; it is created on [framenote.ai](https://framenote.ai). The plugin holds no keys: sign-in happens in FrameNote.
