# FrameNote plugin for Claude Code

The Claude Code plugin marketplace for [FrameNote](https://framenote.ai): scripts, cast, storyboards and video reviews for film and video teams.

```
/plugin marketplace add oshri/framenote-claude-plugin
/plugin install framenote@framenote
```

Then run `/mcp`, choose **framenote** and sign in to FrameNote. See [the plugin's README](plugins/framenote/README.md) for what it does.

This repository is generated from the FrameNote monorepo; changes made here directly are overwritten by the next release.
